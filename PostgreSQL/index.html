安装 Docker

安装 Docker Desktop

访问 https://www.docker.com/products/docker-desktop 下载 Docker Desktop

⚠️注意：windows电脑均下载AMD版本的，不要下载ARM版本的，课堂上说的有误！

配置镜像加速器

由于网络原因，国内用户拉取 Docker 镜像可能很慢，需要配置镜像加速器。

打开 Docker Desktop → Settings → Docker Engine，在配置文件中添加 registry-mirrors：

{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run",
    "https://docker.aityp.com"
  ]
}

点击 Apply & Restart 使配置生效。

验证 Docker 安装

打开终端（Terminal），执行：

docker --version

预期输出（版本号可能不同）：

Docker version 29.2.0, build 0b9d198

验证 Docker 正常运行：

docker info

能看到 Server 相关信息表示安装成功。

安装 PostgreSQL

拉取 PostgreSQL 镜像

docker pull postgres:16

我们选择 PostgreSQL 16，这是目前最新的稳定版本。

创建并运行 PostgreSQL 容器

docker run -d \
  --name pg16 \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=123123 \
  -p 5432:5432 \
  -v "你的本地路径:/var/lib/postgresql/data" \
  postgres:16

参数说明：

参数说明
-d后台运行容器
--name pg16容器命名为 pg16
-e POSTGRES_USER=admin设置超级用户名为 admin
-e POSTGRES_PASSWORD=admin123设置密码为 admin123
-p 5432:5432将宿主机 5432 端口映射到容器 5432 端口
-v ...:/var/lib/postgresql/data数据持久化卷，容器删除后数据不丢失

验证 PostgreSQL 容器

进入容器连接 PostgreSQL

docker exec -it pg16 psql -U admin -d admin

参数说明：

参数说明
docker exec -it pg16在 pg16 容器中执行交互式命令
psql -U admin -d demo_db使用用户 admin 连接 demo_db 数据库

连接成功后，在 demo_db=# 提示符下执行以下命令验证：

-- 查看当前连接信息
\conninfo

-- 列出所有数据库
\l

-- 查看当前用户
SELECT current_user;

-- 退出psql
\q

安装管理工具 pgAdmin

官网地址：https://www.pgadmin.org/

同样使用 Docker 安装：

docker run -d \
  --name pgadmin4 \
  -e PGADMIN_DEFAULT_EMAIL=admin@qq.com \
  -e PGADMIN_DEFAULT_PASSWORD=123123 \
  -p 5050:80 \
  dpage/pgadmin4

参数说明：

参数说明
-e PGADMIN_DEFAULT_EMAIL登录邮箱
-e PGADMIN_DEFAULT_PASSWORD登录密码
-p 5050:80宿主机 5050 端口映射到容器 80 端口
--link pg16:pg16连接到 pg16 容器，网络互通

接下来可以打开浏览器访问 http://localhost:5050
