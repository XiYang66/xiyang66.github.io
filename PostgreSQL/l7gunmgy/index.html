数据库核心概念

什么是SQL

SQL（Structured Query Language，结构化查询语言）是操作关系型数据库的标准语言。无论使用 PostgreSQL、MySQL 还是 Oracle，SQL 的语法都高度通用。

SQL 主要做两件事：

  1. 告诉数据库做什么（而非怎么做）—— SQL 是声明式语言
  2. 操作数据—— 增、删、改、查

SQL的细分

分类全称作用常见关键字
DDLData Definition Language数据定义，操作数据库和表结构CREATE、ALTER、DROP、TRUNCATE
DMLData Manipulation Language数据操作，对表数据进行增删改查INSERT、SELECT、UPDATE、DELETE
DCLData Control Language数据控制，管理用户和权限GRANT、REVOKE
TCLTransaction Control Language事务控制，管理事务BEGIN、COMMIT、ROLLBACK、SAVEPOINT

要操作数据，先得有存放数据的结构。所以学习顺序是 DDL → DML，先建表，再操作数据。

DDL语言

DDL 操作的是结构而非数据，包括：数据库的创建删除、表的创建修改删除等。

数据库操作

-- 创建数据库
CREATE DATABASE demo;

-- 删除数据库
DROP DATABASE demo;

CREATE — 创建表

基本语法：

CREATE TABLE 表名 (
    列名 数据类型 [约束],
    列名 数据类型 [约束],
    ...
);

示例：

CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    age INTEGER CHECK (age > 0),
    score NUMERIC(5,2) DEFAULT 0.00,
    email VARCHAR(100) UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

主键

主键（Primary Key）是表中唯一标识每一行数据的列或列组合。它具有两个核心特性：

  1. 唯一性：主键的值在表中不能重复
  2. 非空：主键的值不能为 NULL
-- 单列主键
CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    ...
);

-- 复合主键（多列联合唯一标识一行）
CREATE TABLE enrollments (
    student_id INT,
    course_id INT,
    enrolled_at TIMESTAMP,
    PRIMARY KEY (student_id, course_id)
);

ALTER — 修改表结构

-- 添加列
ALTER TABLE students ADD COLUMN phone VARCHAR(20);

-- 删除列
ALTER TABLE students DROP COLUMN phone;

-- 修改列的数据类型（现有数据可隐式转换时直接用）
ALTER TABLE students ALTER COLUMN score TYPE NUMERIC(6,2);

-- 无法隐式转换时，用 USING 指定转换规则
ALTER TABLE students ALTER COLUMN score TYPE INTEGER USING score::INTEGER;

-- 设置默认值
ALTER TABLE students ALTER COLUMN score SET DEFAULT 0.00;

-- 移除默认值
ALTER TABLE students ALTER COLUMN score DROP DEFAULT;

-- 添加 NOT NULL 约束
ALTER TABLE students ALTER COLUMN email SET NOT NULL;

-- 添加 CHECK 约束
ALTER TABLE students ADD CONSTRAINT score_check CHECK (score >= 0 AND score <= 100);

-- 重命名列
ALTER TABLE students RENAME COLUMN score TO total_score;

-- 重命名表
ALTER TABLE students RENAME TO pupils;

思考： 修改列的数据类型时，如果已有数据，数据库会尝试做隐式转换。转换失败会报错。

DROP — 删除表

-- 删除表（连带数据一起删除）
DROP TABLE students;

-- 如果表存在才删除，避免报错
DROP TABLE IF EXISTS students;

-- 级联删除（连依赖该表的对象一并删除）
DROP TABLE students CASCADE;

TRUNCATE — 清空表

-- 清空表数据，但保留表结构
TRUNCATE TABLE students;

-- 清空所有关联表的数据
TRUNCATE TABLE students, orders;

DELETE vs TRUNCATE vs DROP：

操作类型是否可回滚速度是否保留结构
DELETE FROMDML是慢（逐行删除，可带 WHERE）保留
TRUNCATEDDL是（PostgreSQL 中支持事务回滚）快（直接重置存储）保留
DROPDDL否最快不保留

小结

操作关键字说明
创建数据库CREATE DATABASE新建一个数据库
删除数据库DROP DATABASE删除整个数据库，数据全丢
创建表CREATE TABLE定义表结构、列和约束
修改表ALTER TABLE增删列、改类型、改约束
删除表DROP TABLE删除表和数据
清空表TRUNCATE TABLE清空数据，保留表结构
