Markdown图片自动上传图床

约 308 字大约 1 分钟

markdown

2026-08-08

当我们编写Markdown文章时，经常需要上传图片到图床，但是每次都需要手动上传再将url粘到文章中，很麻烦。下面是我的解决方法。

github配置

创建一个仓库

可见性一定要设置为公开

创建一个token

右上角点击头像，再点击设置，最后点击开发，再点击个人访问令牌，最后点击生成令牌。 注意： 生成的token只能使用一次，后续需要重新生成。

VSCode 安装 picgo 插件

搜索 picgo 插件，点击安装。

打开 setting.json 文件

加入以下内容 ， 根据你的github配置修改。

  // 选择图床类型
  "picgo.picBed.current": "github",
  // GitHub 图床配置
  "picgo.picBed.github": {
    "repo": "XiYang66/images",// 你的仓库名称
    "token": "你的token",
    "branch": "main",// 你的分支名称
    "customUrl": "https://cdn.jsdelivr.net/gh/XiYang66/images@main"// cdn jsdelivr加速地址
  },
  // 上传后自动插入 Markdown 格式链接
  "picgo.customOutputFormat": "![${uploadedName}](${url})",

测试

打开markdown文件，截屏图片，按住 ctrl + alt + u 即可上传图片到图床。并在文章中插入图片。
