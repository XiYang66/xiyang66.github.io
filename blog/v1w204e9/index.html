markdown基础语法

约 1010 字大约 3 分钟

markdown

2026-08-08

写文档就像搭积木，Markdown 就是最省事的那套积木。

1. 标题

用 # 号表示标题，几个 # 就是几级标题，最多六级。

语法：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

效果：标题字号依次变小，层级分明。

注意：# 和文字之间要留一个空格，否则有些渲染器不认。

2. 段落与换行

段落之间空一行即可。段内换行在行尾加两个空格，或者直接用 <br>。

语法：

这是第一段。

这是第二段。

第一行（行尾加两个空格）
第二行紧跟着换行

3. 文本格式

给文字加粗、倾斜或划掉。

语法：

**这是加粗文字**
*这是斜体文字*
***这是加粗斜体***
~~这是删除线~~
`这是行内代码`

效果：

  • 加粗：强调重点
  • 斜体：辅助说明
  • 删除线：表示废弃
  • 行内代码：高亮代码片段

4. 列表

无序列表

用 -、* 或 + 开头，推荐统一用 -。

- 苹果
- 香蕉
- 西瓜
  - 黑美人
  - 无籽瓜

有序列表

用数字加 . 开头。

1. 打开冰箱
2. 把大象放进去
3. 关上冰箱

嵌套列表缩进 2 个空格或 1 个 Tab 即可。

5. 链接

给文字加上超链接，点了就跳转。

语法：

[显示文字](https://www.example.com)

示例：

[我的 GitHub 主页](https://github.com/XiYang66)

带标题的链接（鼠标悬停显示提示）：

[我的 GitHub 主页](https://github.com/XiYang66 "点我看看")

6. 图片

插入图片，语法和链接很像，前面多一个 !。

语法：

![图片描述](图片地址)

示例：

![可爱的小猫](https://cdn.jsdelivr.net/gh/XiYang66/images@main/cat.png)

GitHub 图床 + jsDelivr CDN，图片又快又稳。

7. 引用

引用别人的话或标注备注，用 > 开头。

语法：

> 这是一段引用内容。
>
> 引用里也可以换段。

嵌套引用：

> 鲁迅说：
>> 我没说过这句话。

8. 代码块

行内代码

用反引号 ` 包裹。

用 `console.log()` 打印日志。

多行代码块

用三个反引号 ``` 包裹，可指定语言高亮。

```javascript
function hello() {
  console.log('Hello, Markdown!');
}
```

支持的语言：javascript、typescript、vue、html、css、python、bash 等。

用三个或以上的 -、* 或 _，推荐用 ---。

- [x] 配置 jsDelivr CDN
- [ ] 写完这篇文档
- [ ] 出门吃顿好的

12. 转义字符

Markdown 中有些符号有特殊含义，想原样显示就加 \ 转义。

语法：

\* 这不是斜体 \*
\# 这不是标题
\` 这不是代码

需要转义的符号：

符号含义
\反斜杠
*斜体/加粗
_斜体/加粗
#标题
>引用
[]链接
()链接地址
`代码
