名词解释

约 450 字大约 2 分钟

2026-08-09

在接触 AI 相关的内容时，经常会遇到一些名词，下面是我对这些名词的解释。

agent

它和传统对话式的AI不同，之前我们多数都是使用对话式AI，你问一句它答上一句。

Agent 它会自动调用工具，相当于给AI添加了手脚,它自己拆解步骤、调工具、查资料、反复试错,直到干完"——像个能独立干活的员工。

Agent 和普通 AI 到底差在哪?

对比普通 LLM(聊天机器人)Agent(智能体)
你给它啥一个问题一个目标
它怎么干生成一段文字就完事自己拆步骤、调工具、循环执行
会不会用工具不会,只会说会调 API、读文件、查数据库、开浏览器
会不会反思不会,答完就完会观察结果,错了能改
典型例子ChatGPT 对话框Cursor 的 AI 编码助手、自动驾驶、自动订票机器人

skill

可以理解为封装好的提示词（Prompt ），把一件事的标准操作流程打包好,让 AI 能反复用、稳定输出。

比方：你教一个脑袋记不住事情笨蛋做菜，你每次都要告诉它先做什么，再做什么，非常的重复。 这时你可以写一个菜谱（skill），把固定好的步骤写好，每次需要做菜时，直接看这个菜谱就行了。

Skill 和 Prompt 的区别

  • Prompt 模式:每次都跟 AI 说"帮我写周报,格式是xxx,要点是xxx,别写空话……"——累死
  • Skill 模式:写好一个"周报 Skill",定义好目标/输入/步骤/输出/约束,以后只说"用周报 Skill,这是本周记录"——省心
